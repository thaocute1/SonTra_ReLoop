# API Contract (nháp)

Cập nhật khi backend/web/mobile thống nhất endpoint. Format gợi ý:

| Method | Endpoint | Mô tả | Auth |
|---|---|---|---|
| POST | /api/auth/login | Đăng nhập | Không |
| GET | /api/tours | Danh sách tour | Không |
| POST | /api/bookings | Đặt tour | Có |
| ... | ... | ... | ... |
